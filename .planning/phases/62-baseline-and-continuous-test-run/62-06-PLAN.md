The D-11 tests, applied per field and per session kind:
1. Present in every sampled session of that kind.
2. Tied to a specific review run and a specific reviewer lane without guessing.
3. Consistent: lane totals match the run total.

Labelling rule (planner's reading of D-11, fixed before the data is read):
- `measured` — all three tests hold, and test 3 was checked against a run total that does not come from adding up the same parts.
- `estimated` — the numbers are present and attributable (tests 1 and 2) but test 3 cannot be checked independently (for example the only run total available is the sum of the parts), or the figure includes something that is not the review (for example wall-clock time that includes the owner's waiting time).
- `missing` — absent in at least one sampled session of that kind, or no field carries it at all.

Verdict rule (fixed before the data is read).
