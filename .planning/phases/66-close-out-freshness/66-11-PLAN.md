<objective>
Repair 999.44 shape 1 on the review side: a decision whose own decided line was removed since the review is re-asked instead of being silently carried to identical text elsewhere.

Purpose: closes the single blocking gap in 66-VERIFICATION.md (SC3 / FRESH-03). The owner chose the wider repair on 2026-11-18.

Mechanism (planner's technical decision, differs from the 66-07 sketch — read this before implementing). 66-07 sketched "do not relocate when the stored line was removed". Probes run during planning show that sketch is wrong in two ways: (a) it breaks the same-edit control, which today is relocated to line 48 and re-asked; (b) if the reviewer reports the same title on the identical text, the fresh finding has the decision's identity, is not stamped, and the old decision stays current — on the same-edit case that is a keep where 2.15.0 re-asks. The repair here keeps relocation exactly as on 2.15.0 and makes the scorer re-ask the moved decision: step 0 remembers each case-2 move; when `REMOVED_LINE_RANGES=` lists the record's stored line (or is empty, so removal cannot be ruled out), the orchestrator adds the pair `[<line>, <line>]` for the relocated line to the map the decision stamp reads (`nearby_line_ranges`). `score.py` then stamps `snapshot.nearby_at` as it already does for the same-edit case, and the decision is re-asked on its own row. Probed: decision `stale` / `nearby` at line 49, scores unchanged, re-decide then Close out writes.

Owner decision (2026-11-18, answered "Re-ask them"): when the tool cannot tell whether a line was deleted (code edited during the fresh review, or the prior state has no reviewed tree), re-ask any decision step 0 moved. The cost is an occasional extra question; it is a deliberate, tested difference from 2.15.0. The no-evidence fallback and the `no_evidence_shape1` / `no_evidence_shift` intended differences are therefore locked scope, not planner discretion.

Output: prose rule + locks, the simulator rule, repaired shape 1 tests, a two-sided differential against literal d5acc19, mutation checks.
</objective>
