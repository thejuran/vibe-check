<feature>
  <name>closeout_fresh.stale_decisions — stale deferred/dismissed decisions judged against the reviewed tree</name>
  <files>plugins/vibe-check/scripts/closeout_fresh.py, plugins/vibe-check/scripts/test_closeout_fresh.py</files>
  <behavior>
    Given a temp repo with src/a.py = base_file() committed, state from tdc.pass1(lines, conf=95, kind) with reviewed_tree = HEAD^{tree} (and, in one case, a store tree from a real _Chain pass with uncommitted reviewed code):
      edit line 10               -> [{hash, kind, "line"}]
      edit line 15 or 5          -> [{hash, kind, "nearby"}]
      edit line 16 or 4          -> []
      insert 20 lines above 10   -> []            (pure shift; reverse numbering)
      20 above + edit old 10     -> cause "line"
      whitespace-only edit of 10 -> cause "line"  (D-07)
      comment appended to 10     -> cause "line"  (D-07)
      git rm src/a.py            -> cause "deleted" (D-06)
      git mv src/a.py src/b.py   -> cause "deleted" (D-06; --no-renames)
      decided file not in reviewed tree (record on untracked path) -> cause "untracked" (D-09)
      reviewed_tree missing / "zz" / not in store / store dir deleted / git fails -> every candidate "unverifiable"
      record with non-int line or path failing PATH_RE -> that record "unverifiable"
      no current decision in state -> [] and zero git calls
      record closed by fix-obsolete verdict (blob matches) -> not a candidate -> []
    _NEARBY_LINES == score._NEARBY_LINES; window membership equals score._nearby_changed for lines 4/5/15/16 around 10.
    Output sorted by (file, line, hash); kind is "deferred" for decision "defer", "dismissed" for "dismiss".
  </behavior>
  <implementation>
    Pure layer: `decided_records(state, blobs)` -> list of (record, decision) using carry_state.open_findings + decision_state == "current" + not _fix_closes(rec, state, last, blobs); decision source = own decisions[hash] or carry_state.covering_decision. `stale_from_ranges(candidates, ranges, reviewed_paths, on_disk)` -> sorted stale list; line set per record = own line + same-hash open copies' lines + covered members' lines (mirror score._nearby_spots: copy before grouped, skip own_line, de-dup). Git layer: `_toplevel(cwd)` (rev-parse --show-toplevel), `_store_env_ro(root)` (scrub GIT_INDEX_FILE/GIT_OBJECT_DIRECTORY/GIT_ALTERNATE_OBJECT_DIRECTORIES; add store as alternate only if isdir; NO makedirs), `_treeish(root, env, oid)` (OBJECT_ID_RE + cat-file -t in {tree, commit}), `changed_ranges(root, reviewed_id)` (git diff -R --no-renames --text *REV_FLAGS reviewed_id -- ; diff_ranges.ranges_from_diff; RangeError -> Unverifiable), `reviewed_files(root, reviewed_id)` (git ls-tree -r -z --name-only). `stale_decisions` composes them; any Unverifiable -> every candidate cause "unverifiable". `_git(root, args, env=None)` is the worktree_snap-style runner with `--no-optional-locks -c core.fsmonitor=false`, argv list, stdin DEVNULL, timeout GIT_TIMEOUT, stderr discarded.
  </implementation>
