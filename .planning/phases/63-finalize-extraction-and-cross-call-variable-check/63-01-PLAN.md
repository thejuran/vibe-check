The three per-file git calls, exactly (list argv, no shell): `["git","rev-parse","HEAD:"+f]`, `["git","diff","--quiet","HEAD","--",f]`, `["git","diff","--cached","--quiet","--",f]`. The repo root comes from `["git","rev-parse","--show-toplevel"]`.

Working directory of the git calls (D-06 parity): all four run with `cwd` = the session's working directory. `head_blobs(state, cwd=None)` passes its `cwd` straight to `_git`, and `None` means the helper's own process cwd, which is where the fence runs and where the model ran these same calls at 2.14.1. The calls are not re-rooted at the repo root. Git reads `HEAD:<file>` from the repo root whatever the cwd, and reads the pathspec after `--` in the two `git diff` calls relative to the cwd; the helper keeps both exactly so, because re-rooting would make it stricter than 2.14.1 when the session sits in a subdirectory.
