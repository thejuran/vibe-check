## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| transcript claims → verdict | model text claiming success must be checked against git |
| committed blobs → verdict | a commit's filenames say nothing about what changed inside the file |
| harness run → owner-facing record | timing, counts and containment must not overstate what a scripted run proves |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
