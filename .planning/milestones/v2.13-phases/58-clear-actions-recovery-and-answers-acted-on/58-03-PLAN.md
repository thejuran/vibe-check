Refs file (written by Claude with the Write tool; owner text only ever here):
```json
{"refs": [
   {"verb": "fix",     "kind": "number",       "n": 5},
   {"verb": "fix",     "kind": "title",        "text": "Browse recovery"},
   {"verb": "dismiss", "kind": "marker",       "marker": "remaining", "count": 7},
   {"verb": "defer",   "kind": "prior_number", "n": 3}
 ],
 "reason": "fixed (owner: \"dismiss the 7 fixed rows\")" | null,
 "close_out": true | false}
```
`verb` ∈ VERBS; `kind` ∈ ("number", "prior_number", "title", "marker"); `marker` ∈ ("remaining", "band:critical", "band:warning", "band:medium", "band:needs-verification", "pending", "changed", "absorbed"); `count` optional int ≥ 1 on any marker; `text` non-empty str.

Resolve output (stdout JSON, exit 0) — or a fixed refusal on stderr, exit 2:
```json
{"ok": false, "stale": false, "needs_reason": false, "close_out": true,
 "refs": [{"status": "one", "rows": [5], "candidates": []},
          {"status": "many", "rows": [], "candidates": [{"label": "#2 app/a.py:10", "title": "…"}, …]}],
 "verbs": {"fix": [5], "dismiss": [1,2,3,4,6,7,8], "defer": []},
 "grammar": "fix 5; dismiss 1,2,3,4,6,7,8 -- fixed (owner: …)" | null,
 "parse_reason": null | "<a batch_parse.REASONS string>"}
```
Statuses: `one` (exactly one row set), `none` (0 rows), `many` (>1 candidate; candidates use `_label(row)` + `_one_line(title)` cut to 80 chars), `count_mismatch` (count given ≠ matched), `conflict` (row already claimed by an earlier ref), `bulk` (`remaining` with no count → grammar `<verb> rest`), `blocked` (`remaining` cannot be computed because another ref is not `one`).
`close_out` is echoed back unchanged and is a SAME-TURN signal only: the prose consumes it in the turn that runs resolve (to append `; then close out` to the echo and to make the Rerun re-enter with the `--close-out-after-rerun` marker, 58-07/58-08); it does not survive the Rerun and no later pass reads `$RESOLVEFILE`. `ok` is true iff every ref is `one` or `bulk`, no conflicts, and `parse_reason` is null. `needs_reason` is true iff `parse_reason == batch_parse.REASON_NO_REASON`. `grammar` is built whenever every ref is `one`/`bulk` (even when the reason is missing, so the follow-up can show it); clause order fix → dismiss → defer; numbers ascending, comma-joined; ` -- <reason>` appended only when reason is a non-empty string. `stale` is true iff `--prior-rows` was given and (prior `at_pass` ≠ current `at_pass` or the ordered `stable_hash` lists differ).

New constants (added to REASONS tuple, each ends with "\n", no owner text):

```python
REASON_PRIOR_ROWS = "refused: prior rows file is missing or malformed\n"
REASON_PRIOR_NEEDED = "refused: a prior-card reference needs --prior-rows\n"
```
